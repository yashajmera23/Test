# Molades skills pack

Thirteen Cursor skills matching the Molades block sheet (Start → Case study).

Install lives in `.cursor/skills/`, `.cursor/rules/`, and `.cursor/commands/`.
Canonical talk and standing rules: `VOICE.md`, `CORE_RULES.md`, `AGENTS.md`, `COMMANDS.md`.

Run `/molades-start` (or say "let's begin") to get one next step.

Older command names (`/molades-define`, `/molades-synthesise`, `/molades-stress`, `/molades-craft`, `/molades-challenge`) still work as aliases.
